1. 관리자 인증

확인 중…
토큰 만드는 법
  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 에서 Only select repositories → rapha-n-site 선택
  3. Permissions → Repository permissions → Contents 를 Read and write 로 설정
  4. 만료 기간을 정하고 생성 → 토큰 문자열을 복사해 위 칸에 붙여넣고 저장

토큰은 이 브라우저의 저장소에만 보관되며 서버로 전송되지 않습니다(GitHub API 호출에만 사용). 다른 기기에서 글을 쓰려면 그 기기에서 다시 등록하세요.
